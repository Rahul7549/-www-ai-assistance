Here's a clean way to reverse a string in JavaScript:

javascript
📋 Copy code
function reverseString(str) { return str.split('').reverse().join(''); } // Usage console.log(reverseString('hello')); // "olleh"

How it works:

  1. split('') — Converts the string into an array of characters
  2. reverse() — Reverses the array in-place
  3. join('') — Joins the array back into a string

Note: This approach doesn't handle Unicode surrogate pairs. For production use, consider using Array.from(str) instead of split('').
